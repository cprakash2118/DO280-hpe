 Imperative Versus Declarative Workflows
 
 Deploy application(s) via Imperative Workflows:-
 $ oc new-project projectName 
 $ oc project -q 
 $ oc new-app --name myapp ImageURL
 
 Example:-
  $ oc new-project ns-myapp 
  $ oc project -q 
  ns-myapp
  $ oc get all 
  No resources found at this namespace.
  $ oc new-app --name myapp httpd:2.4 
  $ oc get pods 
  $ oc get svc 
  $ oc get replicaset 
  $ oc get deployment 
  
  $ oc expose service myapp
  $ oc get route 
  

Deploy application(s) via Declarative Workflows:-

 kubectl create deployment hello-openshift -o yaml --image registry.ocp4.example.com:8443/redhattraining/hello-world-nginx:v1.0 --save-config --dry-run=client > example-deployment.yaml
